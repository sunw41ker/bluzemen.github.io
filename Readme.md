# Страница со списком ачивок сотрудника компании. 
[Перейти](https://bluzemen.github.io/)

От автора:

Т.к. особых требований к "начинке" этого фронтэнда не было, некоторые детали я предположил и исходил из этого.

Каюсь, что не сделал нумерацию, показывающую порядок добавления ачивок. Я обычно работаю строго по ТЗ, но в этот раз немного отошёл от него, ибо хотел реализовать более интересный механизм: ачивки могут получаться несколько раз, а количество раз отображается в уголке ачивки. Если очивка получена один раз - количество раз не показывается. Если более одного - показывается к-во получений и меняется цвет. Для демонстрации, страничка при загрузке заполняется несколькими произвольными ачивками.


Итого:

 * Подключена "классика": JQuery и underscore. При таком размере проекта можно и без них было, но это пример маленького кусочка более-менее большого проекта.
 * Добавлять ачивки можно через achieves.add(*jquery object - container*, 'name', imageUrl)
 * Вид меняется автоматически, при присвоении одной ачивки второй раз и далее, но действует это как и говорилось в ТЗ - по добавлению класса.
 * Старался придерживаться БЭМ, ибо люблю аккуратность и систематичность. Cчитаю, что хороший проект должен поддерживаться чётко и прозрачно.
 * Уже сделав, понял, что для примера лучше было бы выполнить это всё на Marionette(ничего личного, просто я его достаточно хорошо знаю).
